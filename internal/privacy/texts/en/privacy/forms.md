## Forms

What you write into a form on this website (name, e-mail address, subject, message and any fields the operator has added) is stored in the website's database and shown in the admin area. Your IP address and the identifier of your browser are not stored with it. The spam protection works with a hidden field, a signed timestamp and a limit on messages per hour, and sets no cookie. If a mail server is set up, the operator receives a notification by e-mail.
