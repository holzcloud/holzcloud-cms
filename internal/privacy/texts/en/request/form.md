## Making a request

Choose what you would like and give the e-mail address the request is about. Name and note are optional.

[[datenanfrage]]

The form sets no cookie. It stores what you ask for, the e-mail address, the name and note if you give them, and the language of the page, but neither your IP address nor an identifier of your browser. When you send the form, the server keeps your network address in memory for at most one hour to limit abuse of the form; it is never written to the database or to a file. If a mail server is set up, the operator receives a notification by e-mail. You can also make your request another way, for example by e-mail to this address {fillin}.
