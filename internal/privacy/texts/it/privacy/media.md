## Immagini e file

Le immagini e i file di questo sito web si trovano sul suo server e vengono forniti da lì. Al caricamento il sistema rimuove i dati incorporati in un’immagine (EXIF, XMP e IPTC), tra cui la posizione GPS e i dati della fotocamera. Nessuna immagine e nessun file viene caricato da un altro server.
