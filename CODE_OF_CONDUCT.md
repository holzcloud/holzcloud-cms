# Code of conduct

This project is small and the tone in it is unexcited. The text below records
what that means, so that in a dispute it does not first have to be negotiated
what applies here.

## What is expected

Stay factual. Criticism is of the contribution, not of the person: there is
plenty you can object to in a piece of code without talking about whoever wrote
it.

Be patient with people who do not know something yet. Every question that seems
obvious to you was once asked by somebody before you.

Write in German or in English. Both get an answer.

## What is not on

- Belittling anybody for their origin, sex, age, disability, religion or sexual
  orientation
- Insults, including the casual kind
- Sexualised approaches
- Publishing other people's personal details
- Carrying on after somebody has asked you to stop

## Where this applies

In issues, pull requests, commit messages and discussions in this repository. And
in how you behave towards participants elsewhere, so far as it concerns this
project.

## If something happens

Here is the honest account, before you rely on it: a single person decides these
cases. There is no panel, no graduated measures and no appeal against the
decision. Exactly one instrument is available, namely access to this repository —
I have no further leverage, and I would not like to give the impression that it
is otherwise.

I aim for a first reply within a week. That is the same undertaking as in
[SECURITY.md](SECURITY.md), because it is the same person with the same calendar.

## Reporting

Use GitHub's private channel:
[**Report a vulnerability**](https://github.com/holzcloud/holzcloud-cms/security/advisories/new).
That channel is really meant for security vulnerabilities and is used here
because it is the only private one this repository has. Please note in the title
that this is not a vulnerability, so that I do not file it wrongly.

If that is not possible for you, open an issue asking for contact and **without
details**; we will then agree on another way.

What you report stays with me unless you say otherwise.
