<objective>
The standing gate, and the half of it no test can hold.

Two things close this phase. The first is mechanical: `go run ./tools/i18n` must
report `0 offen, 0 verwaist` on all four catalogues it writes. The second is
not: everything a person can see has to have been **seen**, in a browser, once.

**This phase has three properties that no unit test in this repository can
reach**, and each of them is a browser step below rather than a paragraph:

1. **The unstyled lightbox.** D-01's whole argument is that a `:target` overlay
   without its stylesheet does not degrade, it fails. Plan 11-01 constrained the
   markup so that the unstyled case is a coherent page, and plan 11-01's tests
   assert the markup's *shape* — but "is this page readable" is a judgement a
   browser with the stylesheet blocked makes and `go test` does not.
2. **The scroll width of a slideshow.** `.planning/STATE.md:209` records that a
   hidden element outside the normal flow made every page of the `weide` theme
   scroll sideways, and that it was measured in headless Chrome at three widths
   before it was believed. A horizontal scroll container is where that
   reproduces most easily and this phase adds one.
3. **The base layout on the two new admin screens.** `internal/web/render.go:46`
   is a hand-maintained slice; a template missing from it renders as a bare
   fragment with no navigation, no flash area and no `hx-headers` CSRF
   attribute — so every htmx POST from that screen fails CSRF — and `go test
   ./...` stays green throughout. Phase 8's entire closing gate was one such
   omission.

**And the pass runs after the code-review fix round, not before.** In Phase 7,
Phase 8 **and** Phase 9 the verifier found user-visible changes that landed
*after* the pass had already been signed off. Three times is not a coincidence.
Task 2 carries the precondition explicitly and the executor halts on it.

Purpose: QUAL-01 and QUAL-02 for phase 11, ROADMAP criterion 6, and one last
measurement of every number the five waves moved.
Output: four catalogues with nothing open and nothing orphaned, a glossary with
this phase's four words in it, and a browser session with a screenshot per step.
