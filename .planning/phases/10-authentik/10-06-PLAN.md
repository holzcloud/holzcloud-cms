<objective>
One predicate, five call sites, and a dependency that has to be visible.

The developer decided on 2026-09-03 that an Authentik session satisfies the
second-factor requirement, unconditionally. The whole decision lives in one
function:

    // internal/auth/twofactor.go:44
    func MustHaveSecondFactor(role string) bool { return role == "admin" }

It gains a second parameter and nothing else changes shape. The doc comment
above it — "Administrators are, because an administrator can change every
password on the installation, upload a template and reach every site" — gains a
third paragraph rather than being rewritten, because the reason it already gives
is still true and the new clause is a condition on it, not a replacement.

**Both source artifacts are wrong about the size of this change, and it matters.**
`ROADMAP.md` and `10-CONTEXT.md` D-04 both say "one function, one caller at
`:70`". Measured on the tree: `internal/auth/twofactor.go:70`, and
`internal/admin/twofactor.go` at `:167`, `:197`, `:274` and `:402` — **five call
sites**. Four of them decide what a screen says rather than what a middleware
does, and the one at `:274` is the guard that refuses to let an administrator
switch their second factor off. Changing the arity makes the compiler find all
five, which is the reason to change the arity rather than to add a variant.

**And the part that is not a code change at all.** Because this decision makes
this installation's second factor depend on the operator's Authentik enforcing
one, SSO-07 requires the dependency to be **stated in `DEPLOY.md` and shown in
the admin** — not left in a source comment where nobody reads it. `DEPLOY.md` is
plan 10-08. The admin is here, in two places: the person's own account screen,
where they would otherwise see a second factor that is simply absent with no
explanation, and the user list, where an administrator thinks about accounts and
should know what is guarding them.

Purpose: SSO-07 and D-04.
Output: one changed signature, five call sites, one session read, and two
sentences on two screens.

line.** Identifiers, comments, test names and commit messages are English. A
sentence a person reads on a screen is **not** an identifier: it is the German
source string of a catalogue entry, and `tools/i18n` collects it as the key that
`en.json`, `es.json`, `fr.json` and `it.json` translate. Writing these two
sentences in English would mint keys whose source language is wrong and would
make `-write` ask for a German translation of an English string. So the template

`GLOSSARY.md` draws for a German word stored in the database: it is a value, not
an identifier.
