<objective>
The three small kinds the milestone still lacks: `zeit`, `bereich` and `code`.

Each is an hour of work and a second hour of tax — the kind list, the two
subtractive filters, the control, the validation, the resolution, and the three
documents that fail the build if a kind is missing from them. The tax on the
documents is paid once for the whole phase in plan 07-07; everything else is paid
here.

Two of the three carry a decision that was taken against the tree rather than
from preference. `bereich` is a bounded number input and **not** a slider,
because FIELD-05 requires the chosen number to be readable before saving without
JavaScript and `internal/tmplmgr/script.go` rejects the scripted readout that
would make a slider legible (D-07). `code` stays available **inside** a block —
the requirement row that said otherwise was corrected in plan 07-01 — and its
escaping therefore has to happen in the block render path, because a block
freezes to HTML when the page is saved and escaping in the theme would be too
late (D-06).

Purpose: close FIELD-04, FIELD-05 and FIELD-06.
Output: three kinds, three controls, the block-render escaping, and the tests
that hold all of it.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| author's Code field → frozen block HTML | Text an editor types is escaped once at page-save time and stored as HTML bytes; nothing downstream escapes it again. |
| author's Code field → public page render | The same text on a non-block page reaches a theme through `Entry.Text`. |
| browser → page form (`bereich`) | The `min` and `max` attributes are a client-side courtesy; the POST body is not. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-10 | Elevation of Privilege | `renderOwn` in `internal/block/render.go`, the `code` arm | high | mitigate | The value is passed through `html.EscapeString` in the block render path, where the HTML is frozen, and never through `prose`. A test puts a script tag, a quote and an ampersand into a `code` field, renders it, and asserts the output carries the escaped forms and not the raw tag. No `template.HTML` cast exists anywhere on the path. |
| T-07-11 | Elevation of Privilege | a Code field on a non-block page | high | mitigate | `Resolve` yields a plain `string` and `List` puts it in `Entry.Text`; `html/template` escapes it contextually at render. The `code` kind adds no `template.HTML` cast and TEMPLATE-SPEC (plan 07-07) documents that a theme prints `.Text` inside a `<pre>` and never with a raw-HTML helper. |
| T-07-12 | Tampering | `Check` for `KindRange` | high | mitigate | The bounds are enforced server-side in `Check`, inclusively at each end. The `min` and `max` attributes on the input are a courtesy for the person filling the form; a POST that bypasses them is refused with a reason.
