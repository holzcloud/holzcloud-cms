Rewrite the writer in `tools/i18n/main.go` to serialise the whole map through the
standard library, per D-13. Encode the map with `json.NewEncoder` into a

function `json.Indent` into a second buffer with an empty prefix and an empty
indent string, then `os.WriteFile` with the existing `0o644` permission. That pair
is what produces the flush-left, one-entry-per-line shape the seven committed files
already carry — measured byte-exact over all seven in `06-RESEARCH.md`.

Two near-misses that must not be substituted: `Encoder.SetIndent` with two empty
strings is a no-op that emits a single line, and `json.MarshalIndent` always
HTML-escapes with no switch. Both were re-measured this research cycle. The
