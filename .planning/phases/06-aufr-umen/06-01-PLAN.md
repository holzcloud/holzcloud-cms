## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repository → `go` subprocess | `tools/wasm` invokes the host `go` toolchain with an environment it constructs; an inherited `GOFLAGS` or `GOEXPERIMENT` would cross this boundary and change the produced bytes |
| `GOPROXY` / toolchain module download → build host | the pinned `GOTOOLCHAIN` is fetched as a module from a network service |
| committed `.wasm` artifact → CI green signal | the artifact attests to source it may not have been built from |
