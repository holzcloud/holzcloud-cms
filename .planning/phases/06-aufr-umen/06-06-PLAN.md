<objective>
Set the zero point and close the hole: rebuild all ten committed build artifacts
with one pinned compiler in a commit that contains nothing else, then make the
comparison and the catalogue check permanent steps in CI.

Purpose: MAINT-03 and the CI half of MAINT-01. D-04 chooses a deliberately set zero
point over a preserved old state — the committed set today is three compilers deep
and five of six modules stamp a module path that no longer exists. D-08 puts the
comparison on the critical path, before `go test ./...`, so a stale module cannot
produce a green test run. D-15 gives the catalogues the same treatment the module
graph already gets.

Output: ten rebuilt artifacts in an artifact-only commit; two permanent CI steps;
the temporary falsification step removed.

**Ordering, non-negotiable (D-12):** this plan lands the rebuild and the comparison.
Plan 06-07 promotes the skips. Promoting first would give a contributor with a
partial checkout a red suite they cannot fix and would close nothing, because the
hole is that CI never rebuilds.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| committed guest module → wazero host | the rebuilt modules are executed by five e2e tests; a compiler change is a behaviour change until the tests say otherwise |
| commit contents → future `git log -S` | a source change hidden inside a 21 MB artifact commit is unrecoverable by search |
| CI step order → the meaning of a green run | a comparison placed after the tests would let a stale module produce a green test run |
