<objective>
The three documents that fail the build if a carrier is missing from them, the
archive that would otherwise lose what this phase added, and the browser.

Phase 7 added four reflection guards over the theme data contract, and they are
about to bite in a specific way that is worth knowing before writing a line:
`walkContract` fails on an **empty** map or slice, so `SampleData` needs a
*populated* `Bausteinfelder` **and** a populated `Bausteinliste` — while
`MinimalData` needs `Bausteinfelder` with empty values and **no** `Bausteinliste`,
because `field.List` never emits an empty entry and a fixture that invented one
would reject a template for handling the list exactly as the specification says
to. The two are not the same omission and the existing `MinimalData` comment about
`Feldliste` says so already.

The bundle is the item the ROADMAP's build order names at step ⑥ and that
`08-CONTEXT.md`'s D-10 does not repeat. It is planned rather than dropped: an
archive that exports a snippet's fields and silently loses them on import is the
kind of quiet data loss this project avoids everywhere else, and the work is one
struct member, two loops and a test.

Then the browser. ROADMAP criterion 6 is a standing gate and the developer's
standing instruction is that a human-test step is driven through the running
application rather than handed back as a checklist. So it is driven here, with
Playwright against a real server, and what it must show is written down.

Purpose: close SNIP-03's documented half and SNIP-05's archive half, and satisfy
the phase's standing gate.
Output: fixtures, specification, bundle round trip, catalogues, and a browser
pass with evidence.
</objective>
