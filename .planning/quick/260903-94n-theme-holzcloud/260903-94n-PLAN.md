<decisions>
**D-01 — The four woff2 files live in the theme, at `fonts/`, referenced as `/t/fonts/…`.**
`/t/` is served by `internal/public/handler.go` through `web.WriteAsset`, whose table
(`internal/web/asset.go`) maps `.woff2` to `font/woff2` and which adds `X-Content-Type-Options:
nosniff` and `Cache-Control: public, max-age=31536000, immutable`. `/assets/` is
`http.FileServer(http.FS(assetsFS))` (`main.go:685`): Go's built-in MIME table has no woff2
entry and an `embed.FS` file reports a zero ModTime, so the same four files would go out as
an untyped download with no cache headers — 83 KB re-fetched on every navigation, on a Pi.
TEMPLATE-SPEC §2.1 and §4 document `/t/fonts/…` as the sanctioned shape and
`TestExtractTemplateAcceptsBundledFont` locks it in; the theme also stays a valid standalone
archive that can be zipped and uploaded to any install. CLAUDE.md's `/assets/` wording is
honoured in substance — build-time fetch, committed, embedded via `//go:embed assets
templates`, same origin — and Task 1 amends that bullet so the next reader does not
"correct" this back.

**D-02 — `style.css` is assembled, not transcribed.**
Provenance header, then the `@font-face` block, then `$SRC/hc/{tokens,base,components,motif}.css`
concatenated byte-for-byte between two sentinel comments, then the unlayered CMS layer.
Byte-exactness is not stylistic: `--hc-cubes-mask` is a `data:image/svg+xml` URI whose own
comment records that a semicolon inside it broke three downstream copies. Concatenating with
`cat` means no CSS is ever retyped, and the `cmp` gate in Task 1 proves it.

**D-03 — Blocks are restyled through the six generic tokens, not by rewriting `.hc-*` rules.**
See established facts. Anything left over after the token bridge is targeted CSS in the
unlayered layer.

**D-04 — Operator tokens are honoured, brass follows brand.**
`--hc-ink` and `--hc-measure` land by name. The unlayered layer bridges the other four with
the design-system value as the fallback, e.g. `--hc-brass: var(--hc-brand, <the value
tokens.css gives it>)`, and likewise ground←`--hc-paper`, `--hc-font-sans`←`--hc-font`,
`--hc-r`←`--hc-radius`. Read the fallback values out of `tokens.css` at execution time.

**D-05 — `.hc-cubes` is the first child of `<body>`; the skip link is second.**
`motif.css` lifts content with `.hc-cubes ~ *` and makes the header sticky with
`.hc-cubes ~ .hc-bar`, both of which need `.hc-cubes` to come first and the bar to be a
direct sibling of it — not wrapped in a container. TEMPLATE-SPEC §10 asks for the skip link
as the first element in `<body>`; the requirement it is really protecting is that the skip
link is the first *focusable* element, and `.hc-cubes` is an `aria-hidden` decorative div
with no tab stop. Putting the skip link first instead would leave it outside the
`.hc-cubes ~ *` lift and paint it underneath the texture when focused — visibly broken, and
invisible to the test, which only greps for the class name.
</decisions>
