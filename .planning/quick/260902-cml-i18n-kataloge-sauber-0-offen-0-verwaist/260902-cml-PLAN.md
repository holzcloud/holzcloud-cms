<objective>
Make `go run ./tools/i18n` report `0 offen, 0 verwaist` for the four full catalogues, without throwing a single working translation away.

Purpose: docs/offene-punkte.md ("Beim Weiterarbeiten") makes a clean run the standing rule after every text change. Four commits' worth of new admin strings (CSV download, translation matrix, revision compare, activity log) are untranslated, and three keys are reported as orphaned.

Output: complete en/es/fr/it catalogues, a regenerated de-CH.json, and two one-line source fixes that put two live sentences back in front of the extractor.

**Correction to the task brief — read before Task 1.** The brief assumed all three orphans are "German sentences no longer present in the source" and that deleting their four entries is the fix. That is true for exactly one of them. Verified against the source:

1. `Du musst keine Vorlage von Hand schreiben. …Anleitung für KI-Agenten…` — **still in the source**, at `cmd/holzcloud/templates/admin/template_upload.html:12`, but written as a `{{th ` + backtick-quoted literal. `callsInTemplates` in tools/i18n/main.go only matches double-quoted literals, so the extractor no longer sees it. At runtime `th` still looks the sentence up, so the four translations are live. Deleting them would silently untranslate a sentence that four people's admin currently shows correctly.
2. `Inhaltsart entfernt. Die %d Einträge sind noch da und tragen weiter die Kennung „%s“ — ` — **a fragment**. `internal/admin/kind.go:194` passes this literal `+` a second literal to `web.Titlef`. `collectGo` requires `*ast.BasicLit` and a `+` is a `*ast.BinaryExpr`, so nothing is collected; at runtime `Titlef` receives the whole concatenated sentence, which no catalogue has. The fragment entry is dead, and the sentence it came from is untranslated in all four languages.
3. `Text dieser Fassung ansehen` — **a genuine rewording**. Commit 6381da3 replaced it with `Aktuelle Fassung ansehen` (page_form.html:11). The old entry is dead; the new sentence is one of the open keys.

So the treatment is: fix 1 and 2 at the source so the extractor sees the live sentence again, delete the two entries that really are dead (the fragment and the reworded one). This costs two small source edits and keeps four working translations.
</objective>
