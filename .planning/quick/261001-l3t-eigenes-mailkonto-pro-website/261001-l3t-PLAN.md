# Quick 261001-l3t: eigenes Mailkonto pro Website

User decision (AskUserQuestion): "Eigenes Mailkonto" — a full SMTP account per
website, password encrypted in the database, rather than only a sender address
or only a Reply-To.

## Task 1 — storage, encryption, routing
Migration 00059, `mail.Accounts`, `HOLZCLOUD_SECRET_KEY` in config, the queue
and the outbox dispatcher pick the account by website id. Tests: ciphertext at
rest, keep-password, wrong key, no key, value copied to another row, input
validation, routing with and without an installation account.

## Task 2 — admin screen
`/admin/websites/{id}/versand` (GET/POST, test, remove), settings nav entry,
list of websites with own account on /admin/mail, route classification.

## Task 3 — words and documents
Catalogue de/fr/it/es (+ de-CH via -schweiz), configuration.md, security.md,
service unit, README, CHANGELOG 0.0.11.
