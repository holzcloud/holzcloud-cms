## What changed

- **C-01:** `orders.token` (16 random bytes as 32 hex), migration 00060 backfills with `randomblob` and adds a unique index. `OrderStore.ByToken` checks the format before querying and is per website. Routes are now `/bestellung/{token}` and `/zahlung/zurueck/{token}`. Mail link, checkout redirect, payment redirects and the Payrexx return URL use the token. The webhook and the provider reference still use the number. `ByNumber` stays for the admin. TEMPLATE-SPEC notes that the URL carries a token. The README does not document the URL, so it is unchanged.
- **C-02:** `HandleHome` now runs the same gate as `HandlePage` and serves unlocked content via `servePrivate`.
- **C-09:** `applyGateway` acts only from open/failed and only if `gw.ID == PaymentReference`.
- **D-02:** `Accounts.Save` with `keepPassword` returns the new `ErrAccountPasswordNeeded` when host (case-insensitive), port or user changed and a password is stored. The admin form shows it as an error on "password".
- **C-10:** The resolver normalises hosts (lowercase, trimmed, trailing dot) in the middleware and in `lookup`. The cache is capped at 1024 entries with a mutex-guarded counter, still on `sync.Map`.
- **C-11:** `ParseAmount` rejects a whole part longer than 10 digits or above 1e9.

## Deviations from Plan

**1. [Rule 1 - Bug] Home-page unlock route was broken (the check the constraints asked for)**
- **Found during:** Task 2
- **Issue:** The unlock cookie was scoped to `/<slug>` and the redirect went to `/home`. The home page is served at `/`, and `/home` redirects 301 to `/`. The cookie was never sent to `/`, so a correct password led back to the gate in a loop.
- **Fix:** `grantAccess` takes `isHome`. `HandleUnlock` detects the home page via `GetHomePageIn`, sets the cookie with `Path=/` and redirects to `/`. The cookie name carries the page id, so the wider path opens nothing else.
- **Test:** `TestUnlockingTheHomePageSticks`
- **Commit:** 8ab0d1c

**2. [Rule 3 - Blocking] Test fixtures**
- `order.html` added to `testFS` in `internal/public/handler_test.go`, so the confirmation handler can render in tests.
- The existing `TestKontoPasswortVerschluesselt` changed Host with `keepPassword`, which is now refused by design. It now changes `FromName` and the host's case instead.
- The i18n catalogue keys are English in the actual files, despite what CLAUDE.md says. The new key follows the files: "The server, port or user name was changed — please enter the password again."
