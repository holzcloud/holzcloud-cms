<objective>
Write the composer of the privacy template and the register of cookies it prints, and tie both to the code and to the deployment file by tests, so that the text a website publishes cannot say something the program or the host contradicts (DSV-02, DSV-04, DSV-06; decisions D-03, D-04, D-05, D-08).

Purpose: the phase promises "what is set is necessary or triggered by the visitor and stands in the declaration". A hand-written list rots on the first renamed cookie. A register that the code constants feed, a text that is generated from the register and from the log constants, and a source guard that notices a new cookie writer make the promise something the build checks. The text stays a template (D-04): it is generated, marked as unfinished, and left in the operator's hands to complete.

Output: the package `internal/privacy` (language-neutral register in `cookies.go`, the German text in `text.go`), the two exported constants in `internal/page`, the allowlist entry in `tools/english`, and the tests. Plan 30-05 feeds `Compose` from a website's settings and plan 30-06 offers it on the settings screen.

Scope: the page types Impressum and Datenschutz already exist as starter pages (D-07); this plan creates no page type. It writes no admin screen and no form (nothing for the operator to fill per website beyond the visible fill-in markers).
</objective>
