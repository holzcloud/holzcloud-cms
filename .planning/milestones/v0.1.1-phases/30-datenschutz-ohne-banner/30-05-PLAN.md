<objective>
Let the program know which functions a website uses, and compose the starter privacy page of a new website from them (DSV-06; decisions D-04, D-07).

Purpose: plan 30-04 made the template; this plan feeds it. The audit found the starter `datenschutz` page saying the site sets no cookies while a shop on the same website sets one the moment someone adds an item. The detection built here is also what plan 30-06 uses to offer a current template for websites that already exist.

Output: `page.Store.HasProtected`, `Handler.privacyFeatures`, and `starter.go` composing the datenschutz entry. Tests for each state of the detection and for the starter page.

Scope: the starter pages exist (D-07); only the content of the datenschutz entry changes. Existing websites are not touched (D-06): their pages are theirs, and plan 30-06 offers the template as a draft.
</objective>
