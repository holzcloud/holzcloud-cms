A missing or empty FILE is `FAIL (no chain summary)`.
- `srv01_overall MDWE TIMING`: the overall word with the precedence NOT-NATIVE, FAIL, NOT-RUN, VOID, PASS (the first that either input carries wins; PASS only when both are PASS).
