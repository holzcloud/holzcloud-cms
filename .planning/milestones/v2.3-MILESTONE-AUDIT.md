## What made this milestone different

**It measured before it chose.** WORD-04 was written as a requirement and not as
a habit, and it paid: the broad answer — re-render every page's blocks per
request — is elegant, and costs 124 µs and 215 KB on a medium page with no way
to guard it. It is out on a number rather than on an instinct, and the number is
committed as a benchmark so the next person can disagree with evidence.

**It closed a window by removing code.** Window 34 was framed as an architecture
question about where a boundary sits. The answer was to delete the thing on both
sides of it: there is no translator at save any more, so the two that disagreed
cannot. `block.Set.T`, two `t` parameters and `album.Set`'s translator are gone.

**It decided a deferral instead of renewing it.** WIN-08 had been "deliberately
open" through three milestones. A fourth would have made it permanent by
attrition.

## What the audit found that the phase did not plan for

**CI had been red for two days and the project did not notice.** Four plugin
modules were compiled against an older SDK; `tools/wasm -check` said so on every
push. That is a v2.1 defect that two milestones closed on top of. The release
workflow did not run that check at all, so a stale module could have travelled
inside a published tag. It runs it now.

**Three releases had never been made.** v2.0, v2.1 and v2.2 each had a CHANGELOG
entry, a close commit and no tag. They exist now — built and tested by CI from
the code each one names, not made by hand. The route had to be worked out
first, and it is written down in `release.yml` where the next person will look:
this development environment's proxy refuses every write to `refs/tags`, and a
workflow run it *dispatches* carries the wrong scopes, but a run started by a
*push* holds the repository's ordinary token and may publish.

**Three interface faults that only a browser found.** A heading printed twice on
three screens, a CSS custom property this project does not define, and a back
link outside the slot the layout keeps for it. None subtle; none visible to the
test suite. QUAL-02 exists for exactly this and earned its place again.

## Open, deliberately

Nothing. The ledger is empty and no requirement was carried forward.
