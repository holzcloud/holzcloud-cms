## Cross-phase seams

Only one phase, so the usual seam question does not arise. The seam that does
is the one between this milestone and the last: **v1.10 handed over four open
windows about strings a person reads that no catalogue holds** (6, 14, 15, 16),
plus window 3 which v1.10 itself closed. All four are closed here, each with the
mechanism named rather than "done".

## What the audit found that the phase did not plan for

Three decisions were taken *during* the phase and written into `12-CONTEXT.md`
as §3c and §3d, and as the landing note under §3a. That is the right shape — a
decision taken mid-phase belongs with the other decisions, not in a commit
message where the next reader will not look.

- **§3c, the MCP surface.** Not foreseen. Found because `tools/english` reads
  string literals as well as comments, which the criterion's original grep would
  not have. It cost a second breaking change in the same release, announced.
- **§3d, the gate's exception lists.** §3b decided the public side stays German;
  §3d is that decision made enforceable, so the next reader meets it in the gate
  rather than by accident.
- **§3a landed** rather than becoming the carry-over the decision allowed for,
  because the 274 it was sized against turned out to be mostly a visitor's text.

## Open, deliberately

1. **The public side has no translation channel.** A French-language website
   sells in German. This is a feature and not a cleanup: it needs the theme and
   the handler decided together. Recorded in `germanVoice` in
   `tools/english/main.go`, in §3b and §3d of `12-CONTEXT.md`, and in
   `12-VERIFICATION.md`.
2. **`plugin.json`'s name and description are not translated.** A plugin's
   identity in a list, written once by whoever built it. Visible in the browser
   pass as the one German sentence left on `/admin/plugins`.

## Fifteen windows stay open

None of them belongs to this milestone; all fifteen came from v1.6/v1.10 and
are recorded in `WINDOWS.md` with their phase. Window 8 changed shape here and
the entry says so: both gallery words now go through one function, but from two
sources — the inline block carries the operator's language frozen at save time,
the album carries the website's language resolved at delivery.
