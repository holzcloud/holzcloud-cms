  - Set `Content-Disposition: inline` (D-20)
  - `http.ServeFile(w, r, diskPath)` — path traversal safe because filename is UUID-prefixed and looked up from DB
  - **Security:** Validate filename contains no path separators before constructing disk path

| Boundary | Description |
|----------|-------------|
| Public request -> media file | Unauthenticated users access media by filename |
| Public request -> template rendering | Menu data from DB rendered as HTML in public pages |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-11 | Information Disclosure | admin/media.go HandleMediaServe | mitigate | Filename from DB lookup only; validate no path separators; serve from known directory |
| T-04-12 | Tampering | template/loader.go | mitigate | Menu HTML rendered via template.HTMLEscapeString on all user-supplied values (title, URL) |
| T-04-13 | Spoofing | admin/media.go HandleMediaServe | accept | Media is intentionally public; no auth needed; Content-Type from DB not filesystem |
| T-04-14 | Tampering | public/handler.go | mitigate | Menu data loaded from DB only; no user input in menu rendering path |
| T-04-15 | Denial of Service | admin/media.go HandleMediaUpload | mitigate | http.MaxBytesReader enforces 5MB limit before processing |
</threat_model>
