| Boundary | Description |
|----------|-------------|
| Admin upload -> disk | Zip/media files from admin user written to filesystem |
| DB metadata -> disk path | Template slug from DB used to construct filesystem path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | tmplmgr/upload.go | mitigate | filepath.Clean + HasPrefix on every zip entry; reject entire archive on first escape |
| T-04-02 | Tampering | tmplmgr/upload.go | mitigate | Extension allow-list; reject files not in D-02 list |
| T-04-03 | Spoofing | media/upload.go | mitigate | http.DetectContentType on file bytes, not Content-Type header |
| T-04-04 | Denial of Service | tmplmgr/upload.go, media/upload.go | mitigate | http.MaxBytesReader + io.LimitReader enforce size caps |
| T-04-05 | Tampering | media/upload.go | mitigate | UUID-prefixed filenames; never use raw user input in paths |
| T-04-06 | Tampering | tmplmgr/store.go | mitigate | Cannot delete active template (check IsActiveAnywhere before delete) |
</threat_model>
