<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> /admin/login POST | Untrusted email + password credentials |
| Browser -> /admin/setup POST | Untrusted initial admin credentials |
| Session cookie -> Server | Client presents session token for server-side lookup |
| X-CSRF-Token header -> gorilla/csrf | CSRF token validated on all non-GET admin requests |
| htmx AJAX -> Server | All state-changing htmx requests must carry CSRF token |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-09 | Spoofing | login.go | mitigate | Same error for wrong email/password; Argon2id with constant-time compare |
| T-02-10 | Spoofing | session cookie | mitigate | HttpOnly, SameSite=Lax, Secure in prod; session rotation on login |
| T-02-11 | Tampering | CSRF | mitigate | gorilla/csrf on all /admin/* non-GET; token in body hx-headers for htmx |
| T-02-12 | Information Disclosure | setup.go | mitigate | Setup returns 404 once users exist; no user enumeration |
| T-02-13 | Elevation of Privilege | main.go routing | mitigate | RequireAuth on protected routes; RequireAdmin available for admin-only routes |
| T-02-14 | Tampering | setup.go | mitigate | Race condition: INSERT with unique constraint + check hasUsers before insert |
| T-02-15 | Information Disclosure | base.html | mitigate | CSRF token scoped to session; no server version headers exposed |
</threat_model>
