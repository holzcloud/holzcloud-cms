## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| internet → /healthz | Public endpoint; returns no user data |
| internet → /assets/ | Serves only embedded static files; no filesystem traversal |
| env → DataDir path | Operator-controlled; used in MkdirAll with 0o700 permissions |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | /healthz | accept | Returns only `{"status":"ok"}`; no version, no DB info, no config values |
| T-02-02 | Tampering | /assets/ via http.FileServer | mitigate | Serving from embed.FS (in-memory, read-only); http.FileServer cannot write; no path traversal possible — embed.FS is a sealed virtual filesystem |
| T-02-03 | Denial of Service | HTTP server without timeouts | mitigate | ReadTimeout=5s, WriteTimeout=30s, IdleTimeout=120s set on http.Server; prevents slowloris and idle connection exhaustion |
| T-02-04 | Denial of Service | Graceful shutdown — hung requests blocking exit | mitigate | context.WithTimeout(10s) on server.Shutdown; SIGKILL from systemd at TimeoutStopSec=15 catches any stragglers — document in Phase 5 systemd unit |
</threat_model>
