   - Handler struct: pageStore *page.Store, loader *template.Loader.
   - NewHandler(pageStore, loader) *Handler
   - ErrHandler wrapper (same pattern as admin).
   - HandleHome(w, r) error: get website from context (WebsiteFromContext). Call pageStore.GetHomePage(ctx, website.ID). If no page, render 404. Otherwise render with "home.html" template. Apply caching headers.
   - HandlePage(w, r) error: get website from context. Extract slug from URL path (r.PathValue("slug")). Call pageStore.GetPublishedPage(ctx, website.ID, slug) -- this enforces D-13 published-only. If nil/error, call Render404 (per D-24). Otherwise render "page.html" with caching headers.
   - serveCached(w, r, content []byte, modTime time.Time): per D-22:
     - Set Cache-Control: public, max-age=300
     - Compute ETag: MD5 hex of content, wrapped in quotes
     - Set Last-Modified from page.UpdatedAt
     - Check If-None-Match -> 304 if match
     - Check If-Modified-Since -> 304 if not newer
     - Otherwise write content with text/html charset
   - HandleTemplateAsset(w, r) error: serve static files from template directory (CSS, images). Per D-23: Cache-Control: public, max-age=31536000, immutable. Serve from disk first, fallback to embedded default/style.css.
   - Set Vary: HX-Request on page handlers (in case htmx is used for public navigation in future).

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public URL slug -> page query | Visitor-controlled URL path used to look up pages |
| Stored content_html -> browser | Pre-sanitized HTML rendered in public template |
| Host header -> site resolution | Visitor-controlled Host determines which site content to show |
| If-None-Match/If-Modified-Since -> 304 | Client-controlled cache headers affect response |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-11 | Information Disclosure | public/handler.go | mitigate | Only GetPublishedPage used (enforces status='published'); drafts never served publicly |
| T-03-12 | Tampering | template/loader.go safeHTML | accept | content_html is pre-sanitized by bluemonday on save; safeHTML cast is safe. Comment documents this. |
| T-03-13 | Spoofing | public/handler.go cache headers | mitigate | ETag computed from actual content hash; cannot be forged. If-None-Match compared server-side. |
| T-03-14 | Information Disclosure | public/handler.go 404 | mitigate | 404 page uses site's template but reveals no page titles, slugs, or draft content |
| T-03-15 | Denial of Service | template/loader.go cache | accept | Template cache per website_id; bounded by number of websites (tiny on Pi) |
| T-03-16 | Tampering | Host header | mitigate | Domain resolver strips port, does exact match against DB; no wildcard or regex matching |
</threat_model>
