<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Admin form input -> SQL | Website name, page title/slug/content from forms |
| Markdown content -> stored HTML | User content rendered later in public templates |
| URL path params -> SQL queries | Website ID and page ID from URL path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Injection | admin/website.go, admin/page.go | mitigate | All SQL via parameterized queries in store layer; handlers never build SQL |
| T-03-07 | Tampering | admin/page.go | mitigate | Markdown rendered via goldmark then sanitized via bluemonday UGCPolicy before storage; XSS stripped on save |
| T-03-08 | Elevation of Privilege | admin routes | mitigate | All routes behind requireAuth middleware; CSRF on all POST/PUT/DELETE |
| T-03-09 | Tampering | admin/page.go inline edit | mitigate | Inline edit PUT validates page belongs to website (check website_id match); CSRF token required |
| T-03-10 | Information Disclosure | page store | mitigate | Admin page queries are scoped by website_id; no cross-website data access |
</threat_model>
