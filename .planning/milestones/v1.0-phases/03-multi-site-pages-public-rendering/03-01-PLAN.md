<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host header -> domain resolver | Untrusted client controls Host value |
| Markdown content -> HTML output | User-authored content rendered in browser |
| URL slug -> SQL query | User-controlled slug used in WHERE clause |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing | domain/resolver.go | mitigate | Strip port from Host, COLLATE NOCASE on domain column, exact match only |
| T-03-02 | Information Disclosure | domain/resolver.go | mitigate | Unknown hosts get generic 404 with no site data — no website names, no domain lists |
| T-03-03 | Tampering | page/markdown.go | mitigate | bluemonday UGCPolicy() strips scripts, on* attributes, dangerous tags after goldmark render |
| T-03-04 | Injection | page/store.go, domain/store.go | mitigate | All SQL uses parameterized queries ($name), never string concatenation |
| T-03-05 | Denial of Service | domain/resolver.go sync.Map | accept | sync.Map grows unbounded but domain count is tiny (dozens max on Pi); cache replaced on invalidation |
</threat_model>
