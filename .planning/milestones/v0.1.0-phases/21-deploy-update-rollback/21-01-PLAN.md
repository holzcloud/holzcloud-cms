## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host to privileged container | files go in only through `docker cp`; no host path is mounted and no port is published |
| curl in the container to the service on loopback | the headless First Run posts credentials and a CSRF token |
| local git history and Go module download to the built binary | the binary that gets installed is built from a named ref |
